## 📌 Project Overview
A console-based, menu-driven Student Record and Result Management System built primarily in C. This project enables academic record management (SAP ID, Roll No, Name, Contact, Academic Year, Semester, and SGPA across all 8 semesters) and incorporates an AI-assisted Academic Advisor logic using structured if-else decision rules.

## 🚀 Status
- [x] Initial C Program Structure & Data Models
- [x] Student Record Functions (Add with validation, Search by SAP ID, Delete with array shift, Formatted Display)
- [x] CGPA Calculation & Year-wise Average Reporting
- [x] Sorting Algorithms (SAP ID & Alphabetical Name using Bubble Sort)
- [ ] AI-Assisted Academic Advisor

## 🛠 Features Implemented in this Phase
- **CGPA Calculation**: Computes individual cumulative GPA by averaging valid, non-zero semester SGPAs.
- **Year-wise Average CGPA**: Aggregates and reports cohort-level performance across Year 1, Year 2, Year 3, and Year 4.
- **Sort by SAP ID**: Bubble sort sorting student records in ascending numeric order of SAP ID.
- **Sort by Name**: Alphabetical ascending bubble sort using `strcmp` on student names.
